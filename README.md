# IPL Data Analysis (2008–2020)

## Project Overview
This project focuses on analyzing Indian Premier League (IPL) data from 2008 to 2020 using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Matches played in each IPL season
- Top run-scoring batsmen
- Most sixes and fours
- Highest individual scores
- Most wickets by bowlers
- Most dot balls
- Team performance analysis
- Powerplay run analysis
- Most centuries and half-centuries
- Bowling performance analysis

## Project File
`IPL_DATA_ANALYSIS2008-2020.ipynb`

## Dataset
IPL ball-by-ball dataset (2008–2020).
